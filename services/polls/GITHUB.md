# Архив прежнего сервиса Sites

Исходный код сохранён для истории (коммит 684551748b6469dbacc7d1c10d9bd5406d655796). Действующий сайт использует GitHub Pages, компоненты components/polls/ и PHP API на REG.RU из services/reg-api/. Этот каталог не участвует в его сборке и работе.

Опросы и ответы находятся в data/polls.json. Сессии и настройки действующего API хранятся в закрытом каталоге REG.RU вне сайта. Инструкции по серверу: services/reg-api/README.md.
