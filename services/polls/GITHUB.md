# Сервис опросов

Полный исходный код действующего сервиса. Исходный коммит: 684551748b6469dbacc7d1c10d9bd5406d655796.

Основной сайт размещён на GitHub Pages. Данные опросов: `/data/polls.json` в ветке main. Этот сервис выполняется в Sites и принимает анонимные ответы через API; GitHub Pages не выполняет этот серверный код. Копирование исходников не меняет действующий сервер и не настраивает автоматическую публикацию его изменений.

## Локальная работа

Откройте эту папку как отдельный проект. Установите зависимости через npm.cmd ci. Проверки: node --test tests/admin-security.test.mjs; npx.cmd tsc --noEmit. Сборка: node scripts/run-framework.mjs build.

Необходимые серверные секреты: POLL_GITHUB_TOKEN, POLL_PASSWORD_HASH, POLL_RATE_SECRET. Значения хранятся в настройках сервера, не в Git. D1 DB обслуживает сессии и ограничение попыток входа; старые опросы оставлены в D1 как резервная копия. Структура базы и миграции находятся в db/ и drizzle/.

Полное отключение Sites требует развертывания этого API на другом сервере, переноса секретов и авторизации, затем смены адресов iframe в основном сайте.
