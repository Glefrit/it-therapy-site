# Опросы и анонимные ответы

Активное хранилище — data/polls.json. Новые опросы, ответы и удаления автоматически сохраняются сервером в GitHub. Перенос из D1 завершён 24 сентября 2026 года; d1MigrationCompleted=true. Идентификаторы сохранены, прежние QR-ссылки работают.

Одновременные изменения защищены проверкой SHA и повтором при конфликте. При ошибке GitHub отправка возвращает ошибку, не показывая успешное сохранение. Система рассчитана на небольшие опросы: действуют ограничения GitHub API; предел текущего JSON-файла примерно 900 КБ.

Пароли, ключи и сессии не публикуются. Секрет POLL_GITHUB_TOKEN хранится на сервере и требует обновления при истечении срока. D1 используется для входа и защиты от перебора; прежние опросы и ответы оставлены там как резервная копия и больше не обновляются.

Репозиторий публичный. Удаление опроса из панели удаляет его из текущего файла и закрывает приём ответов, но предыдущие версии остаются в истории Git.
