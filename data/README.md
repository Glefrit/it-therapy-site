# Опросы и анонимные ответы

`polls.json` — проверенная выгрузка существующих опросов и ответов из сервиса опросов. Идентификаторы и время создания сохранены. Пароли, сессии, IP-адреса и ключи доступа в выгрузку не входят.

## Текущий статус

Это снимок данных на дату `exportedAt`, а не активное хранилище сайта. Новые ответы пока сохраняются в существующую D1. Не удаляйте D1 до завершения переключения и сверки данных.

Для автоматической записи в GitHub серверу нужен отдельный fine-grained token с доступом только к `Glefrit/it-therapy-site` и разрешением Contents: Read and write. Ключ хранится только в серверном секрете `POLL_GITHUB_TOKEN`, никогда в репозитории или клиентском коде. Перед переключением необходимы повторная выгрузка актуальных данных, реализация записи с проверкой SHA и повтором при конфликте, проверка одновременных ответов и удаления опроса.

Репозиторий публичный: содержимое ответов доступно всем. Удаление файла или ответа в новой версии не удаляет его из истории Git.
