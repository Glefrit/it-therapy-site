# Опросы и анонимные ответы

Активное хранилище — data/polls.json в ветке main. PHP API на REG.RU (https://api.it-therapy.ru) автоматически сохраняет новые опросы, ответы и удаления в GitHub. Страницы работают на GitHub Pages: https://it-therapy.ru/oprosy/. Sites и D1 для их работы не нужны.

Перенос данных из D1 завершён 24 сентября 2026 года; d1MigrationCompleted=true. Идентификаторы сохранены. Постоянные ссылки: https://it-therapy.ru/oprosy/otvet/?id=ID.

Одновременные изменения защищены проверкой SHA и повтором при конфликте. При ошибке GitHub отправка возвращает ошибку, не показывая успешное сохранение. Система рассчитана на небольшие опросы: действуют ограничения GitHub API; предел текущего JSON-файла примерно 900 КБ.

Секрет GitHub, хеш пароля, сессии и защита входа хранятся в закрытом каталоге REG.RU вне сайта и не публикуются. Токен необходимо обновлять при истечении срока. Установка и обслуживание описаны в services/reg-api/README.md.

Репозиторий публичный. Удаление опроса из панели удаляет его из текущего файла и закрывает приём ответов, но предыдущие версии остаются в истории Git.
